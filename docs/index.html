Narrative Studio

把灵感聊清楚，把正文留在手上。

给中文长篇创作者的一张本地写作桌。带来一篇没写完的稿子，或带来一句还不成形的灵感。你可以先讨论、再看候选，最后自己决定要留下哪一段。

在本机试用看续写演示

今天想怎么写？

01 / CONTINUE

接着旧稿写

导入 TXT 或 Markdown，定位光标或选中文本。先看候选，确认后保存，也能撤销。

02 / PLAN

从一句灵感开始

自由讨论，或按卡片梳理人物、关系和剧情。确认后把方案带进开篇。

03 / EDIT

留点空间给自己

只打开正文也可以写、改、保存和导出。私人稿件保存在本机 Vault。
